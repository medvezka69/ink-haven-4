# Story Haven

СОЗДАЙ ПОЛНОЦЕННУЮ ВЕБ-ПЛАТФОРМУ ДЛЯ ПИСАТЕЛЕЙ И ЧИТАТЕЛЕЙ

Создай современное полноценное веб-приложение для писателей и читателей. Это НЕ интернет-магазин и НЕ платный сервис. Все основные функции платформы должны быть бесплатными.

Главная идея:

Пользователь может написать собственную книгу в удобном редакторе, сохранить её, оформить, опубликовать и позволить другим людям читать её. Одновременно пользователь может читать книги других авторов, подписываться на авторов, добавлять книги в библиотеку, ставить лайки, комментировать и взаимодействовать с сообществом.

Платформа должна объединять:

профессиональный редактор книг, похожий на Microsoft Word;

библиотеку книг;

красивый режим чтения как настоящей электронной книги;

социальную сеть для писателей и читателей;

AI-помощника для авторов;

профили пользователей;

подписки;

лайки;

комментарии;

уведомления;

поиск и рекомендации.

Не копируй дизайн существующих платформ. Создай оригинальный современный интерфейс.

28. AI API

Интегрируй AI через безопасную серверную архитектуру.

API-ключи никогда не должны находиться непосредственно в клиентском коде.

Создай backend/server-side функцию для AI-запросов.

AI должен получать только необходимый контекст книги.

Не отправляй всю книгу при каждом запросе, если это не требуется.

У каждого:

аватар;

описание;

1–2 книги.

Добавь несколько жанров, комментариев, лайков и подписок, чтобы интерфейс сразу выглядел живым.

Но архитектура должна быть построена так, чтобы после подключения Supabase эти данные заменились реальными пользовательскими данными.

34. ГЛАВНОЕ ВПЕЧАТЛЕНИЕ

Сайт должен ощущаться не как обычный текстовый редактор.

Он должен ощущаться как:

«Место, где я могу написать свою книгу, найти своих читателей и самому открыть для себя тысячи новых историй.»

Автор должен чувствовать:

«Это моя писательская студия.»

Читатель должен чувствовать:

«Это моя библиотека.»

А вся платформа должна ощущаться как:

«Моё литературное пространство.»

Сделай интерфейс оригинальным, профессиональным, современным и действительно удобным.

Не делай копию Word или Wattpad.

Возьми лучшие принципы редакторов документов, электронных библиотек и социальных платформ, но создай собственную цельную систему.

Начни с создания полной архитектуры приложения, базы данных и основных страниц, а затем реализуй рабочий интерфейс.
